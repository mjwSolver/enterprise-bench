## 1. Executive Summary

Enterprise consulting and presales presentations frequently suffer from severe visual debt accumulated through rapid, cut-and-paste assembly. The 36-slide presales modernization deck (`Modernize_Data_Platform_Pitch_Deck_Template.pptx`) exemplifies this legacy pattern:
- **Low-DPI Bitmap Paste-Ins:** System screenshots (SAP ERP, Snowflake UI, Streamlit analytics) are pasted haphazardly into slide canvases at arbitrary aspect ratios, frequently overlapping body copy and floating over baseline card borders.
- **Clipart & Hand-Drawn Diagrams:** Architectural topologies and data flow concepts are assembled with ad-hoc PowerPoint freeform shapes, mismatched 3D monitor clipart, inconsistent elbow connectors, and manually grouped boxes that break when repositioned.
- **Unformatted Bullet Dumps:** Crucial scope-of-work, assumption, and KPI narratives are dumped as wall-of-text bullets without typographic hierarchy, leading, or scannability.
- **"Logo Soups":** Over 45 vendor and technology logos are pasted into single slides without grid alignment, normalized bounding boxes, or transparent alpha handling, creating cognitive fatigue and brand degradation.
- **Maintenance Nightmare:** Because screenshots and diagrams are flattened bitmaps or brittle freeform groupings, making a minor client tweak (e.g., changing an ingestion cadence from "Monthly" to "Scheduled Batch") requires recapturing full application windows, re-cropping images, and realigning text layers manually.

```
+--------------------------------------------------------------------------------------------------+
|                                    LEGACY TECHNICAL DEBT                                         |
|  [Pasted ERP Screenshot]      [3D Clipart Monitor]       [Unaligned 45-Logo Soup]   [Raw Text]   |
|   - Overlapping text           - Brittle freeform shapes  - Inconsistent scale       - No cards  |
|   - Low resolution (<96 DPI)   - Ad-hoc connector routes  - Harsh white backgrounds  - 8pt font  |
+--------------------------------------------------------------------------------------------------+
                                                 │
                                                 ▼ TRANSFORMATION
+--------------------------------------------------------------------------------------------------+
|                                MODERN CODE-DRIVEN CONSULTING STACK                               |
|  [Browser Mockup Frame]       [Native DrawIO / SVG Flow] [Standardized Vector Grid] [Card Flow]  |
|   - 300+ DPI retina capture    - Layered pipeline AST     - Curated SVG logos        - Split hero|
|   - macOS window controls      - Orthogonal smart routing - Normalized viewports     - Stepped   |
|   - Structured telemetry pill  - Live theme injection     - High-contrast badges       chevrons  |
+--------------------------------------------------------------------------------------------------+
```

This backlog defines the engineering blueprint and design specifications to systematically refactor the 36-slide presales deck from brittle bitmap paste-ups into deterministic, modular, high-contrast OpenXML consulting artifacts generated by `enterprise-bench`.

## 3. Target Modernization Archetypes & Engine Components

To replace the visual debt documented above, four core engine primitives must be implemented and extended across `src/ppt_engine/`.

### Archetype A: Native Draw.io / SVG Pipeline Architecture Integration

> **Target Slides:** Slide 24 (Architecture with 3D Clipart Monitor), Slide 23 (Proposed Architecture), Slide 07 (Orchestration Flow)  
> **Subsystems:** `src/ppt_engine/diagram_engine.py`, `src/ppt_engine/consulting_archetypes.py`

#### 1. The Anti-Pattern
Slide 24 embeds a low-resolution Streamlit screenshot inside an illustrative 3D monitor shape, flanked by manual rounded boxes and curved connectors. The diagram cannot be themed, rescaled, or searched, and updates require a graphic designer.

#### 2. The Architectural Solution
Replace manual diagram shapes with **declarative Draw.io AST topologies** that compile directly into transparent or white-background SVG/PNG assets, dynamically injected into PowerPoint slides as high-DPI shapes.

```
+---------------------------------------------------------------------------------------------------+
|  INGESTION TIER             LAKEHOUSE TIER (Snowflake)              CONSUMPTION TIER              |
|  ┌──────────────────┐       ┌──────────────────────────────┐       ┌───────────────────────────┐  |
|  │  [AWS S3]        │       │  ┌────────────────────────┐  │       │  [Streamlit UI]           │  |
|  │  Raw Staging     │──────▶│  │ Bronze: Raw Parquet    │  │──────▶│  Financial Analytics App  │  |
|  └──────────────────┘       │  └───────────┬────────────┘  │       │  - Executive Dashboard    │  |
|  ┌──────────────────┐       │              ▼               │       │  - Opex & Margin Explorer │  |
|  │  [SAP ERP CDC]   │       │  ┌────────────────────────┐  │       └─────────────┬─────────────┘  |
|  │  Financial Data  │──────▶│  │ Silver: Cleansed DWH   │  │                     │                |
|  └──────────────────┘       │  └───────────┬────────────┘  │       ┌─────────────▼─────────────┐  |
|  ┌──────────────────┐       │              ▼               │       │  [Cortex AI]              │  |
|  │  [Manual CSV]    │       │  ┌────────────────────────┐  │       │  LLM Narration Summaries  │  |
|  │  Tsusho Upload   │──────▶│  │ Gold: Financial Marts  │  │──────▶│  Automated Monthly Brief  │  |
|  └──────────────────┘       │  └────────────────────────┘  │       └───────────────────────────┘  |
|                             └──────────────────────────────┘                                      |
+---------------------------------------------------------------------------------------------------+
```

#### 3. Engine Implementation Specification
1. **Model Representation (`DrawIOProject`):** Store topology in `output/<project>/diagrams/01_pitch_deck.drawio` with dedicated tab `Solution Architecture`.
2. **Vector Logo Injection:** Each node assigns an official SVG icon from `assets/logos/` (e.g., `amazons3.svg`, `snowflake.svg`, `dbt.svg`) using the unified asset resolver.
3. **Aspect Ratio Governance:** Strictly enforce multi-tier columnar layout (aspect ratio $2.8:1$ to $3.2:1$) to avoid ribbon distortion on 16:9 slides.
4. **Slide Injection Hook:**
   ```python
   def build_pipeline_architecture_slide(
       prs: Presentation,
       diagram_path: Path,
       title: str,
       subtitle: str,
       takeaway_bullets: List[str],
       theme: ThemeConfig,
   ) -> Slide:
       """Renders architecture diagram on the left (w=8.2") with structured takeaway card on the right (w=4.2")."""
   ```

> **Target Slides:** Slide 20 (Raw SAP ERP Window), Slides 28–29 (Streamlit Prototypes)


#### 3. Technical Parameters
- **Window Chrome:**
  - Header bar height: `0.32"` with slate fill (`#1E293B` for dark chrome, `#F1F5F9` for light chrome).
  - Traffic light controls: Red (`#EF4444`), Yellow (`#F59E0B`), Green (`#10B981`) circles with diameter `0.10"`.
  - Address bar pill: Centered rounded pill (`h=0.20"`, fill `#FFFFFF`, text `7pt Mono`).
- **Container Body:**
  - Inner image slot with 1px hairline border (`#CBD5E1`) and subtle ambient shadow.
  - Automatic cropping and padding to eliminate messy desktop taskbars or OS titlebars.
- **Supporting Telemetry Pills:** Bottom-anchored status indicators reporting runtime environment, security classification, or data latency.

> **Target Slides:** Slide 06 (Product Portfolio), Slide 07 (Orchestration Tools), Slide 08 (Certifications), Slide 10 (Customer References)

## 5. Rigorous Acceptance Criteria

Every modernized slide generated by the engine must strictly adhere to the following verified criteria:

1. **Zero Raw Unpadded Screenshots:**
   - No application screenshots may be pasted directly onto slide canvases without a structured container.
   - All UI previews must be framed within `BrowserMockupContainer` or `SideBySideProofCard` with high-DPI scaling ($\ge 200\text{ DPI}$).
2. **Zero 3D Clipart or Hand-Drawn Powerpoint Polygons:**
   - 3D monitor clipart, freeform iceberg shapes, and manual elbow connectors are completely eliminated.
   - All system architectures and process flows must compile from declarative Draw.io XML or programmatic OpenXML shapes.
3. **100% Vector Technology Logos:**
   - Every technology and vendor mark must render from vector SVG source files in `assets/logos/` or normalized crisp PNG fallbacks.
   - Zero blurred, low-resolution bitmap logos or white-box bounding artifacts.
4. **Strict Header & Geometry Standard Compliance:**
   - **Unified Title & Subtitle:** Action Title and Subtitle must flow within the *same* text box with a `10pt` paragraph spacing offset, eliminating coordinate collisions.
   - **Zero Top-Stripe Overlap:** Container cards with accent stripes must use sharp rectangles (`MSO_SHAPE.RECTANGLE`), never rounded rectangles.
   - **Cover Slide Typographic Metadata:** Cover slide metadata must render directly on the background in clean multi-column layouts with zero boxed cards, footers, or page numbers.
5. **Legibility & Typographic Scale:**
   - All body copy, captions, and diagram labels must maintain a minimum optical size of $\ge 10\text{pt}$ (cards) and $\ge 11\text{pt}$ (diagram nodes).
   - High-contrast compliance: Minimum $4.5:1$ contrast ratio for all text against card fills and slide backgrounds.
6. **Unified Stage-Gate Compliance:**
   - Deliverable artifacts must pass standard validation checks in `enterprise-bench-ops` and conform to [`LIFECYCLE.md`](../LIFECYCLE.md) Presales phase requirements.
